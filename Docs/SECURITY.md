# 安全

> [!WARNING]
> AIStudio将所有数据保存在本地，但仍建议遵循良好的安全实践。
> ⚠️ AI models may make mistakes, so double-check outputs.

## 漏洞报告

- 请**不要**为安全漏洞创建**公开** issue。
- 请通过仓库维护者私密报告（issue 平台的私密安全通告，或仓库中列出的
  联系方式）。
- 报告内容请包含：受影响版本、复现步骤、潜在影响，以及可行的修复建议。
- 我们承诺在 **7 天内**确认收到报告，并尽快发布修复。

## 受支持的版本

| 版本 | 是否支持 |
| ------- | --------- |
| 最新发布版本 | ✅ 支持 |
| 任何历史版本 | ❌ 均不支持 — 请升级 |

## 密码保护

AIStudio 的可选密码是**本地隐私锁，而非安全边界**：

- **纯客户端实现**：锁屏（`PasswordGate` 组件）只在浏览器层面隐藏界面。
  后端 API 路由**没有任何鉴权**——任何能通过网络访问该服务的人都可以
  直接调用 `/api/*` 读取全部数据，完全绕过锁屏。
- **存储方式**：密码哈希存于 `localStorage`；解锁状态存于
  `sessionStorage`（关闭标签页失效，硬刷新强制重新验证）。
- **哈希算法**：简单的 32 位非加密哈希，**无盐值、无迭代拉伸**，
  不能抵御暴力破解或字典攻击。
- **无速率限制**：连续输错不会触发锁定。
- **找回密码**：忘记密码的唯一方式是清空全部数据（三步确认 +
  手动输入 "DELETE ALL"）。

因此：请将应用保持在 `localhost`（或受信任的网络）上运行，真正的
访问控制应依赖操作系统级别的防护。不要指望该密码能防住任何拥有网络访问权限或文件系统访问权限的人。

## 安全最佳实践

- **API Key**：仅保存在本地 SQLite 数据库（`data/ai-studio.db`）中。
  切勿分享该文件，也不要将其提交到版本库（默认已被 gitignore 忽略）。
- **密码保护**：可在设置中启用可选锁屏来限制应用访问。请注意这是本地
  便捷锁，不能替代操作系统级别的访问控制。
- **网络暴露**：除非你了解相应风险，否则请仅在 `localhost` 运行本应用；
  API 路由本身没有身份验证。
- **代理设置**：如果配置了代理，请确保你信任它——所有 LLM 流量都会 经过代理。
- **依赖管理**：定期运行 `npm audit` 并保持依赖更新。

## 数据流向

- 对话、设置与用量统计永远不会离开你的电脑，唯一例外是**你主动**向自己配置的接口发送对话请求。
- Edge-TTS 请求会将你选择朗读的文本发送到微软的 TTS 服务。
