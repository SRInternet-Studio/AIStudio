# 行为准则

## 我们的承诺

我们承诺让参与本项目的每个人都能获得友好、包容、免受骚扰的体验，无论
其年龄、体型、残障状况、族裔、性别认同与表达、经验水平、国籍、个人
外貌、种族、宗教或性取向如何。

## 我们的标准

**期望的行为：**

- 使用友好、包容的语言。
- 尊重不同的观点与经验。
- 虚心接受建设性批评。
- 以社区与项目的利益为先。

**不可接受的行为：**

- 骚扰、恶意挑衅、侮辱性或贬损性评论、人身或政治攻击。
- 未经许可公开他人隐私信息。
- 灌水、与项目无关的自我推广或商业招揽——本项目明确**非商业**性质。
- 任何在专业环境中可被合理认定为不当的行为。

## 执行

- 不可接受的行为可通过 issue 平台或仓库中列出的联系方式向维护者举报。
- 维护者将及时、公正地审查举报，并可视情况删除、编辑或拒绝相关内容，
  或封禁违规者。
- 所有举报将在可能的范围内保密处理。

## 署名

精神上改编自 [Contributor Covenant](https://www.contributor-covenant.org/)
及常见开源社区行为准则。
